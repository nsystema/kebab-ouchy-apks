# Applications Android Kebab Ouchy

Ce depot contient uniquement les applications Android signees de l’equipe et leurs empreintes. Le code source et les donnees du restaurant ne sont pas publies ici.

[Telecharger Cuisine et Livreur](https://github.com/nsystema/kebab-ouchy-apks/releases/latest)

Le telechargement est accessible sans compte GitHub. Installez l’application correspondant a votre role, puis ouvrez votre invitation personnelle et connectez-vous avec le compte Google autorise par le restaurant. L’installation seule ne donne aucun droit sur les commandes.

Les fichiers SHA256SUMS et BUILD-INFO.json de chaque version permettent de verifier les APK. Les fichiers release-certificate.der contiennent uniquement le certificat public de signature.
